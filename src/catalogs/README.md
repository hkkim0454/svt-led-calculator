# catalogs — 제품 카탈로그 · 데이터시트 PDF

제품 정보 팝업(ⓘ)의 **카탈로그 바로 보기 / 다운로드**가 여는 파일을 둔다.
목록은 `src/product-docs.js` 의 `PRODUCT_DOCS` 에 한 줄씩 적는다(파일만 넣으면 화면에 나오지 않는다).

## 꼭 지킬 것

- 배포 사이트(GitHub Pages)는 **공개 사이트**다. 주소를 아는 누구나 이 폴더의 파일을 받을 수 있다.
  **제조사가 공개한 카탈로그·데이터시트만** 넣는다. 가격표·견적·계약·내부 문서는 넣지 않는다.
- 파일 하나는 수십 MB 이하로 둔다(저장소와 화면이 무거워진다).

## 파일 이름

`제조사-라인-종류-판.pdf` — 소문자·하이픈만 쓴다.

- 예) `samsung-mpf-catalog-2026.pdf`, `samsung-mm012f-s-datasheet-2026.pdf`
